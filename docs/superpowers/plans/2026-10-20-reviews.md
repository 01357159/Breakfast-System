# Customer Reviews Implementation Plan

> Execute inline in this session, following the approved guest ordering and Google sign-in flow.

**Goal:** Add verified ratings and reviews with customer ownership and owner replies.

**Architecture:** Supabase Google Auth and private Postgres tables behind narrowly scoped RPC functions. Guest receipt secrets bridge checkout and optional subsequent Google sign-in. Existing local ordering remains available without backend configuration.

**Tech Stack:** React, React Router, Supabase JS, Postgres SQL, Node test runner and PGlite for database authorization checks.

## Execution result

Local implementation finished on `codex/customer-reviews`. Four tests pass, including database authorization and checkout retry coverage. Lint, production build and `git diff --check` pass. A separate code review found stale checkout retry and unrefreshed order status issues; both were addressed. Browser verification was attempted but the browser tool could not reach the Windows localhost server. The target Supabase project denied connector access; no hosted schema or Google OAuth settings have been changed. Follow `docs/reviews-setup.md` to complete external configuration.
